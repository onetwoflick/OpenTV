# OpenTV

Premier Smart IPTV Player for Android TV & Samsung Smart TVs.

## Download
Latest Release: [OpenTV.apk](https://raw.githubusercontent.com/onetwoflick/OpenTV/main/OpenTV.apk) (v2.2.0)

## Features
- **Xtream Codes API Integration**: Stream Live TV and Movies (VOD) directly from your IPTV provider.
- **Curated Malayalam & English Feeds**: Dedicated rows for Malayalam (`AS | IN | MALAYALAM` & `VOD | IN | MALAYALAM`) and English channels & 4K movies.
- **Slide-Out Quick Channel Guide**: Press **Left Arrow (◀)** or **Guide** button on your TV remote to browse and switch channels without leaving playback.
- **Multi-Stream Failover**: Automatic switching between high-speed alternative CDN streams.
- **In-App Auto Updates**: Built-in check-for-updates system fetching latest APK releases directly from GitHub.
